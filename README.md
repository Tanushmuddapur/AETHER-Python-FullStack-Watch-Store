# AETHER Horology — Beyond Time

A full-stack luxury horology e-commerce web application built with **Python & Django**, featuring an adaptive **Light & Midnight Teal Dark Mode** interface, **Liquid Glass** UI surfaces, a bespoke **Atelier Hybrid Studio** component builder, booking/invoice receipts, and an administrative command center.

**Live Demo:** [https://aether-python-fullstack-watch-store.onrender.com/](https://aether-python-fullstack-watch-store.onrender.com/)

---

## Key Features

* **Editorial Storefront & Adaptive Themes:** Contrast between a warm light mode hero and deep Midnight Teal dark mode with frosted Liquid Glass cards and subtle interactive polish.
* **Atelier Hybrid Studio:** Bespoke timepiece configurator allowing users to combine cases, dials, movements, and custom engravings with interactive colorway previews.
* **Catalog, Offers & Checkout Flow:** Browse curated timepieces, apply promo/bank offers, complete booking reservations, and generate itemized booking/tax invoices.
* **Administrative Command Center:** Manage inventory, bookings, and operational workflows from a centralized admin interface.
* **Production Deployment:** Configured for cloud hosting on Render with Gunicorn and WhiteNoise for static asset delivery.

---

## Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3 (Liquid Glass & Light/Midnight Teal themes), JavaScript
* **Database:** SQLite / relational ORM models
* **Deployment:** Render, Gunicorn, WhiteNoise
